There are two components for adding `Element Props`.

1.  TypeSript
2.  Props declaration

---

## TypeScript `cn.rs`

In here we check the the class value from the `className` and check if there is any conflict with `clsx` with and tailwinds that going to put in there with `twMerge`.

```
ts

import { clsx } from "clsx";
import { twMerge } from "tailwind-merge";
import { ClassValue } from "clsx";

export function cn(...args: ClassValue[]) {
  return twMerge(clsx(args));
}


```

## Props `Props.tsx`

In here we combine the TypeScript check with the actual class value.

```
import * as React from "react";
import { cn } from "../utility/cn";

interface InputProps extends React.ComponentPropsWithRef<"input"> {}

export function Input({ className, ...props }: InputProps) {
  return (
    <input
      {...props}
      className={cn(
        "w-full p-2 bg-gray-100 border border-gray-300 rounded-md focus:outline-none focus:ring-2 focus:ring-blue-500",
        className
      )}
    />
  );
}

interface LabelProps extends React.ComponentPropsWithRef<"label"> {}

export function Label({ className, ...props }: LabelProps) {
  return (
    <label
      {...props}
      className={cn("block mb-1 font-medium text-gray-700", className)}
    />
  );
}


```

### Syntax

```
ts

export function Input({ className, ...props }: InputProps)
```

This is three things at once:

1. Function parameter
2. Object destructuring
3. Type annotation

Which is the same as:

```
ts

export function Input(props: InputProps) {
  const className = props.className
  const restProps = { ...props, className: undefined }
}

```

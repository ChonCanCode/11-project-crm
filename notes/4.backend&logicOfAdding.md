I’ll assume:

- You have **multiple `.json` files** (e.g. `1.json`, `2.json`, etc.)
- Each file represents **one property**
- You want to **prevent duplicates** based on **street + postcode**
- This logic runs on the **backend (Node.js)** — not in React

> ⚠️ Important: **You cannot safely do this directly in React**.
> React must call an **API** that performs the check and save.

## ✅ Correct approach (industry standard)

### Flow

1. React form submits data
2. Backend:

   - Checks if **street + postcode already exists**
   - If yes → reject
   - If no → create new file with new ID

## 🧠 Backend logic (Node.js example)

### 1️⃣ Read all existing properties

```js
import fs from "fs";
import path from "path";

const dataDir = path.join(process.cwd(), "data");

const getAllProperties = () => {
  const files = fs.readdirSync(dataDir);

  return files.map((file) => {
    const filePath = path.join(dataDir, file);
    return JSON.parse(fs.readFileSync(filePath, "utf-8"));
  });
};
```

---

### 2️⃣ Check if property already exists (street + postcode)

```js
const propertyExists = (street, postcode) => {
  const properties = getAllProperties();

  return properties.some(
    (p) =>
      p.street.toLowerCase().trim() === street.toLowerCase().trim() &&
      p.postcode.toLowerCase().trim() === postcode.toLowerCase().trim()
  );
};
```

✔ Case-insensitive
✔ Prevents duplicates cleanly

---

### 3️⃣ Create new property safely

```js
const addProperty = (newProperty) => {
  if (propertyExists(newProperty.street, newProperty.postcode)) {
    throw new Error("Property already exists");
  }

  const properties = getAllProperties();
  const newId = properties.length + 1;

  const propertyWithId = {
    ...newProperty,
    id: String(newId),
  };

  const filePath = path.join(dataDir, `${newId}.json`);
  fs.writeFileSync(filePath, JSON.stringify(propertyWithId, null, 2));

  return propertyWithId;
};
```

## 🌐 Example API route (Express)

```js
app.post("/properties", (req, res) => {
  try {
    const property = addProperty(req.body);
    res.status(201).json(property);
  } catch (error) {
    res.status(400).json({ message: error.message });
  }
});
```

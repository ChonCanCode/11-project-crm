## Step 1 - server.js

```
server.js

const express = require("express")
const mongoose = require("mongoose")

const app = express();

app.use(express.json())


```

### What does app.use() mean?

This means use `.use()` this middleware for incoming requests.

- app = your server
- Requests come in -> pass through **middleware** -> reach routes -> send response.
- Runs for every HTTP method (GET, POST, PUT, DELETE)
- Runs for every matching path
- Used for:
  - parsing JSON
  - authentication
  - logging
  - error handling

### What does app.get() mean?

It handles GET requests, only runs when URL matches & sends a response.

### What does express.json() mean?

Use the JSON-parsing middleware provided by Express. One-line mental model: Hey express please understand JSON!

- It looks at the request body -> if it is JSON parses it & attaches it to req.body.

### Why require () and not import?

This is abou **module systems**. Node.js traditionally uses CommonJS. import is ES Modules (ESM)

ESM only works if:

- `"type": "module"` is in `package.json`
- OR file extension is `.mjs`

---

## What this code actually does

### 1️⃣ You create a **schema** (blueprint)

```js
const propertySchema = new mongoose.Schema({
  street: String,
  city: String,
  postcode: String,
  tenant: String,
  rent: Number,
  status: String,
});
```

This:

- Defines **what a Property document looks like**
- Specifies field names + types
- Does **nothing** with the database yet

Think of this as:

> “A rulebook for Property documents”

No queries, no collection, no data.

---

### 2️⃣ This is the important line

```js
module.exports = mongoose.model("Property", propertySchema);
```

This line does **three things at once** 👇

---

## 🔹 Thing #1: Registers a model with Mongoose

```js
mongoose.model("Property", propertySchema);
```

- Tells Mongoose:

  > “There is a model called `Property` and it uses this schema”

- Mongoose stores this internally in its model registry

This matters because:

- Mongoose prevents duplicate model names
- You can retrieve the same model later with:

  ```js
  mongoose.model("Property");
  ```

---

## 🔹 Thing #2: Creates a **Model class**

The return value of:

```js
mongoose.model(...)
```

Is a **Model** (a constructor function / class).

That Model:

- Represents the **`properties` collection**
- Has static methods:
  - `Property.find()`
  - `Property.findById()`
  - `Property.create()`

- Has instance methods:
  - `property.save()`
  - `property.remove()`

So when you do:

```js
const property = new Property(req.body);
```

You are:

- Creating a **document instance**
- Based on the schema
- Connected to the DB collection

---

## 🔹 Thing #3: Exports that Model

```js
module.exports = <Model>
```

This makes the **Model** available to other files:

```js
import Property from "../models/Property";
```

Now other files can:

- Query the database
- Create documents
- Update/delete records

---

## The `"Property"` string (again, super important)

```js
mongoose.model("Property", propertySchema);
```

That string:

- Is the **model name**
- Determines the MongoDB collection:
  - `"Property"` → `properties`

- Is how Mongoose internally identifies the model

If you changed it:

```js
mongoose.model("RealEstate", propertySchema);
```

Everything would still work — but now MongoDB would use:

```
realestates
```

---

## The one-sentence explanation

> This code defines the shape of a Property document, creates a Mongoose model tied to the `properties` collection, and exports that model so the rest of the app can read/write Property data.

---

## Analogy (quick intuition)

- **Schema** = blueprint
- **Model** = factory + query API
- **Document** = actual record in MongoDB
- **Collection** = table (loosely speaking)

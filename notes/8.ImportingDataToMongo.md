## 2️⃣ Example JSON file format

  },

Place it somewhere clear, for example:

```txt

```

(Create the `data` folder if it doesn’t exist.)

---

## 3️⃣ Seed script (`seed.js`)

```js
const mongoose = require("mongoose");
const dotenv = require("dotenv");
const Property = require("./models/Property");

dotenv.config();

const seedProperties = async () => {
  try {
    await mongoose.connect(process.env.MONGO_URI);

    console.log("MongoDB connected for seeding");

    const data = require("./data/properties.json");

    // Clear existing data (optional)
    await Property.deleteMany();

    // Insert new data
    await Property.insertMany(data);

    console.log("✅ Properties seeded successfully");
    process.exit();
  } catch (error) {
    console.error("❌ Seeding error:", error);
    process.exit(1);
  }
};

seedProperties();
```

# ⚠️ Common JSON → Mongo mistakes to avoid

### ❌ `_id` in JSON

If your JSON has `_id`, Mongo may reject it.

✔️ Remove `_id` fields unless you really need them.

---

### ❌ Fields don’t match schema

If your `Property` schema requires fields not in JSON, insert will fail.

✔️ Either:

- Add missing fields to JSON
- OR make schema fields optional

---

### ❌ Dates as strings

Mongo is fine with ISO strings:

```json
"createdAt": "2024-01-01T10:00:00Z"
```
